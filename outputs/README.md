# Local output files

This folder holds generated files. Existing files were moved here without changing their contents.

- `screenshots/`: previous GUI screenshots and diffraction plots.
- `data/`: saved MATLAB data from earlier experiments.
- `validation/`: saved figures and reports from validation runs.
- `archive/`: older beam-path comparison folders, preserving their original names.

These generated files stay local and are ignored by Git. The reproducible public documentation figure is in `docs/assets/`.

For new saved results, choose a subfolder here. No simulation loads these historical files as required input.
