# Optical Bench

A standalone browser edition of the MATLAB optical-lithography teaching simulator. All calculations run locally in a browser worker, with no MATLAB installation, external API, or account required by the app itself. The hosted Site is owner-private.

Run a local HTTP server with `python3 -m http.server 8765 --directory dist`, then open http://127.0.0.1:8765. A web server is needed for module workers; opening index.html as a file is not supported.

The interface includes selectable components, all original source and mask types, circular/noncircular/freeform pupils, linked ideal 4f geometry, a movable observation screen, source/mask/pupil/screen plots, a central intensity profile and visible horizontal XZ / vertical YZ wave views, including 0–200 µm near-mask diffraction. The MATLAB application is preserved unchanged.

The physics port uses double-precision complex FFTs, incoherent Gaussian source quadrature, a soft Gaussian condenser aperture, pixel-area mask sampling, a finite pupil, Rayleigh–Sommerfeld / angular-spectrum near-mask propagation, Fresnel defocus and Bluestein evaluation of Collins propagation for intermediate relay planes. UI lens surfaces and mechanical mounts are illustrative.

Preview: 128 mask samples per side and 7×7 source bins. Standard: 256 and 13×13. Fine: 512 and 25×25. The original 201×201 source distribution is binned by weighted centroid. XY and wave views now use the same detail settings. Fine uses the maximum exposed grid (512), 2× propagation padding and 25×25 weighted source bins (445 emitters for the default circular source). Preview results and per-plane brightness normalization must not be interpreted as a convergence guarantee.

Run numerical verification using `npm test`. MATLAB fixtures can be regenerated by running `tests/export_matlab_reference.m` in MATLAB from any working directory. The tests cover an independent direct DFT, analytic Gaussian propagation, closed aperture, numerical guards, energy weights, geometry and MATLAB parity at mask/image/intermediate planes.

Known limits: scalar, paraxial, low-NA model; no polarization, real lens surfaces/materials, aberrations, resist exposure model or whole-reticle propagation. Pre-mask intensity uses analytic Gaussian source-cell integrals; post-mask fields use finite incoherent source quadrature. Freeform editing uses a 32×32 piecewise-constant pattern. Refine sampling before drawing quantitative conclusions. No backend or GPU is required.

Detailed feature comparison and remaining MATLAB gaps: [MATLAB_PARITY.md](MATLAB_PARITY.md). Test coverage and browser checks: [TEST_REPORT.md](TEST_REPORT.md).

## Startup view and layout

The page order is optical bench → screen results → wave intensity. The optional central profile opens in a keyboard-accessible dialog. Wave component symbols align to their physical z positions; selecting a point offers a local “Show this slice” action. One compact header replaces the repeated titles; About the model and Reset bench are in its More menu.

On phones, the complete geometric path fits the available width in both orientations, with scaled schematic components and More rays always shown. Physical longitudinal distances remain proportional; component heights are illustrative. Components above the path opens a bottom sheet with seven large selection buttons and the existing parameter controls. Closing the sheet restores focus, and moving between mobile and desktop preserves the settings. Explanations are expandable and contact details no longer occupy the main page.

On both desktop and phone, the Explore / Key positions switch sits directly under the beam. The observation-position slider, exact position, plane shortcuts and Show slice are grouped below it; these controls hide in Key positions mode. Fine focus expands on demand. Dragging changes the selected position immediately, while Show slice updates the result; the figure keeps its actual calculated z and a pending notice until completion. The intensity profile is in the observation image's options menu.

Wave intensity places transparent component outlines directly in the plot, using the displayed result's physical z coordinates. The fixed Image marker differs from the movable screen cursor. The overlay can be hidden without changing the numerical data, and does not intercept plot selection. XZ/YZ have direct buttons. Detail, brightness, cache information and instructions are inside Wave settings (a gear on phones); only actionable calculation notices appear outside it.

Startup and Reset bench select the circular pupil experiment. The annular pupil remains a separate experiment with inner/outer radius 0.65.

The default full-path wave loads from `dist/data/default-wave-circular-fine-v4.json`: a genuine 512-grid, 445-emitter XZ/YZ calculation made by the same numerical engine, with no browser wave calculation at startup. The ordinary XY image still calculates locally. The wave cache includes every default z column, both raw cuts and physical coordinates, so section and brightness changes are immediate. A parameter/version key prevents reuse after optical changes; reset or restoration of exact defaults reuses the saved result. The cache is a bundled read-only asset, not browser storage or a backend.

The wave plot interpolates raw intensity and the changing transverse window between saved z planes. Fractional pixel coverage smooths the window edges, and the canvas uses the screen pixel density (up to 2×). Thin component transitions remain at their physical planes. This display interpolation does not add propagation samples or change the Fine cache; gray means outside the calculated window.

Regenerate with `node scripts/precompute-wave.mjs` when the optical engine or defaults change. For a pupil-only change, `--reuse-upstream <saved-cache.json>` can retain raw pre-pupil columns after checking the engine hash and every non-pupil parameter; the pupil and all downstream planes and the shared intensity reference are recalculated. `npm test` checks the engine hash, cache parameters, malformed data, and fresh Fine calculations before, at and after the pupil. Fine wave updates for modified optics can take a long time, especially on phones; use Preview for quick experiments. The precomputed default removes that delay from startup.

### Reference planes and observation screen

Key positions always displays Source, Mask, Pupil and the fixed ideal Image plane. A separate Observation screen provides position, near-focus offset and a popup horizontal intensity profile. Update all views refreshes both; Show slice refreshes only the movable screen. Pending position/settings changes retain the previous labeled plot until calculation completes. Default startup is a circular pupil with the saved Fine XZ/YZ wave.

On desktop, tablet and phone, these results share a two-position sliding tab control: Explore any position is first and selected on startup; Fixed reference planes displays Key positions. Click, tap, swipe the control, or use arrow keys to switch without calculating again. Exactly one panel is visible at a time, including after resizing. The observation image comes before its controls on portrait phones and sits beside them on desktop and landscape phones. Display settings contains the same detail and brightness controls for both tabs. Show this slice from the wave plot opens Explore automatically on every screen size.

The independent observation screen includes position and near-focus controls. Moving it preserves the fixed Image Plane and the default wave cache. Touch controls have 44-pixel targets; the component picker supports narrow screens, plots reflow in portrait/landscape, and text can enlarge to 200%. Full-image calculations remain in a cancellable worker. Wave propagation caches at most 128 MiB of numerical operators and computes the Collins central cuts directly, with independent full-2D and MATLAB regression comparisons.
